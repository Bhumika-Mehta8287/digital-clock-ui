# Digital Clock UI

A simple yet elegant digital clock built using HTML, CSS, and JavaScript. This project showcases real-time time updates, smooth animations, and a gradient design, making it visually appealing and interactive. It serves as an excellent example of how to use basic web technologies to create a functional and engaging user interface.

## Features
- Displays current time (hours, minutes, and seconds) in a digital format.
- Smooth animation transitions for clock updates.
- Gradient color scheme for a modern look.
- Responsive design for both desktop and mobile devices.

## Technologies Used
- **HTML** for the structure and content.
- **CSS** for styling with gradient effects and responsive layout.
- **JavaScript** for real-time time updates and animation.
